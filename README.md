# RadarXmadrid

Dashboard de eventos de barrio (talleres, centros culturales, actividades juveniles y de mayores) en Madrid, con un modelo sencillo de predicción de demanda por distrito y mes.

## Objetivo

Visibilizar la oferta de eventos medianos/pequeños de Madrid, que suele quedar oculta frente a los grandes conciertos y espectáculos.

## Datos

Portal de Datos Abiertos del Ayuntamiento de Madrid ([datos.madrid.es](https://datos.madrid.es)) — Agenda de actividades y eventos.

## Plan de trabajo

1. Limpieza de datos (pandas)
2. Dashboard interactivo (Dash + Plotly)
3. Modelo de predicción (scikit-learn)
4. Despliegue en Render

## Stack

Python · pandas · scikit-learn · Dash · Plotly · Render
